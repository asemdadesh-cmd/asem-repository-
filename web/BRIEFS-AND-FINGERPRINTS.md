# Briefs and fingerprints

`Self-authored under explicit creative delegation.` The owner asked for "five creative websites for different types of business" and
left the creative direction to the builder. These are the authored briefs, in the scroll-craft format (journey, feeling curve, peak,
tell-someone sentence, grammar choice, signature move). All brands and listings are fictional concepts.

Assets: no image-generation key or stock access was available, so every visual is original SVG, canvas or CSS built for the page. Nothing is a photograph.

---

## 1. Haldane & Rowe, estate agent
- **Journey:** see the register → the street builds itself, one house at a time → shortlist → book a valuation.
- **Grammar:** gallery / catalogue. The other seven lost: the content is a range of objects (homes), not an argument, a tool or a film.
- **Feeling curve:** calm recognition (a clean drawn house) → quiet delight (each house gets built as it arrives) → trust (identical fact labels, no pitch) → resolve (the valuation plate).
- **Peak:** the moment a house finishes building and its windows light.
- **Tell-someone sentence:** "It's the site where the houses draw themselves as you walk down the street."
- **Signature move:** per-house survey → build → light, driven by each house's own position in the viewport, on one continuous datum line.

## 2. Altura, coffee roaster
- **Journey:** above the clouds → why altitude matters → the origin → the roast → the three roasts → reserve the one you stopped at.
- **Grammar:** filmic one-shot (carries the burden of proof). It fits because the story is one linear arc with one emotional build. Chaptered needs long-form, live surface needs a tool, continuous world needs flight video, typographic needs a verbal identity, gallery is only three lots, split has no two sides, cutlist is an energy brand.
- **Feeling curve:** awe → unease at "most coffee" → curiosity → tension (the roast) → relief and ownership (the range) → warmth (the order).
- **Peak:** first crack, when the Drop button opens.
- **Tell-someone sentence:** "It's the site where you roast the coffee by scrolling and stop it where you like it."
- **Signature move:** scroll runs a roast in real phases (beans, drum, curve, first crack). Drop carries the roast level into the range, the header and the order.

## 3. Iron Round, boxing gym
- **Journey:** hit the hero → the four things a session is → the week → three rules → pick a corner → book.
- **Grammar:** rhythmic cutlist. Short hard cuts, painted grounds, no pin, no dwell.
- **Feeling curve:** impact → rhythm → clarity (the timetable) → drive (rules) → decision → urgency (last 10 seconds) → release (the bell).
- **Peak:** the last ten seconds, held in the fixed chrome so every act stays short.
- **Tell-someone sentence:** "It's the site that's one three-minute round and only runs while you scroll."
- **Signature move:** the round clock counts down with scroll position; the last ten seconds take over the screen, and a bell flash lands on the final cut.

## 4. Tannour, wood-fired Levantine restaurant (English / Arabic)
- **Journey:** the name → one sentence → fire, bread, smoke, salt → the menu → come hungry → where and when.
- **Grammar:** typographic poster. Type is the imagery; the close is the smallest type on the page.
- **Feeling curve:** presence (the name fills the screen) → entering (zoom into the loop) → appetite (four words) → plain pleasure (menu) → push → quiet.
- **Peak:** the Arabic name becoming the oven mouth.
- **Tell-someone sentence:** "It's the site where you walk into the Arabic name, and it works properly in both languages."
- **Signature move:** scale about the glyph loop of the waw, plus a live English / Arabic switch (LTR / RTL) that keeps the reader's place.

## 5. Sundial, rooftop solar installer
- **Journey:** the roof → place panels → see the year → see the bill and payback → request a survey.
- **Grammar:** live surface. The page is a working estimator; copy lives in labels, status lines and a help panel.
- **Feeling curve:** orientation → building → proof (the monthly bars) → payoff (payback) → commitment (the input).
- **Peak:** the payback line crossing the cost line.
- **Tell-someone sentence:** "It's the site that is the estimator, and you can change the house while it plays."
- **Signature move:** scroll plays the build while every control stays live; the same model drives the roof drawing, the numbers and the survey request. All constants are listed on the page and labelled as a sample model.

## 6. Northlight Studio, the sales site
- **Journey:** same business, different first impression → five reasons → let's build yours → the work → packages → process → questions → contact.
- **Grammar:** split stage. A template site and a Northlight site are held side by side; the divider carries the argument; the collapse is the ending.
- **Peak:** the collapse, when the template column closes and the offer takes the whole page.
- **Signature move:** divider-carried argument and collapse. After the collapse the winning column becomes the rest of the page (work, packages, process, FAQ, contact).

## Fingerprint gate

Six dimensions: grammar, nav treatment, hero device, act-sequence shape, close pattern, signature move. Each build must differ from every other on at least 4 of 6.

| Site | Grammar | Nav treatment | Hero device | Act-sequence shape | Close pattern | Signature move |
|---|---|---|---|---|---|---|
| Haldane & Rowe | gallery | object index (ref codes, jumps) | object one, already in view | one pan act: six objects + plate | enquiry plate typeset as a label | per-house survey / build / light |
| Altura | filmic one-shot | minimal bar + altimeter | layered SVG descent (parallax pin) | pin > pin > flow+reveal > pin (peak) > pan > pin | pinned close, spotlight + magnet | scroll-run roast, Drop carries level |
| Iron Round | rhythmic cutlist | loud bar: ticker + clock + CTA | one-screen cut: glove + giant type | eleven hard-cut flow sections | full-bleed CTA block | scroll-driven round clock, last 10 s |
| Tannour | typographic poster | none (two quiet controls) | name at poster scale, scaled about the glyph | pin > flow > pin > flow (hard bone) > pin > flow | smallest type, underlined link | walk into the waw + RTL switch |
| Sundial | live surface | app chrome: sidebar, tabs, status bar | the surface already in a state | one pin act, five steps | an actual input form | scroll plays the build, controls stay live |
| Northlight | split stage | divider chrome | 50/50 split | pin (split) > flow tail | collapse | divider-carried argument and collapse |

**Result:** every pair differs on 6 of 6 dimensions. Gate passed. (Registry rows are the table above; there were no earlier builds.)
